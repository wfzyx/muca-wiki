# Ancient Sets

Itens **Ancient** ficam acima de normais e Excellent. Cada peça traz uma **Ancient Option**
(atributo) e, ao equipar mais peças do **mesmo** Ancient, ativam-se os **Set Options**. Cada
**set base tem dois Ancients**. Veja cada um com a imagem oficial e o comando in-game (`/nome`).

> Ancients dropam em **Chaos Castle**, **Land of Trials** e do **Rei Kundun**. A imagem em cada
> página é a do tutorial oficial — é a **fonte da verdade** dos valores.
