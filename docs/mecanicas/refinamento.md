# Refinamento & Jewel of Harmony

O sistema de refinamento permite adicionar e melhorar **opcionais amarelos** em itens
excelentes ou comuns, aumentando drasticamente o poder de combate em PvP e PvM.

## Gemstones & Jewel of Harmony
Para obter uma **Jewel of Harmony (JOH)**, você deve levar **Gemstones** (dropadas em Kanturu) até Elpis, na **Refinery Tower** (Torre de Refinação).
- **Sucesso:** 80% de chance de converter Gemstone em JOH.
- **Como usar:** Arraste a JOH sobre o item desejado. Há uma chance de falha (o item não quebra, mas a joia some).

## Adicionais de Harmony
Cada tipo de item recebe bônus específicos ao usar uma JOH. Estes bônus podem ser evoluídos usando **Refining Stones**.

### ⚔️ Armas (Swords, Bows, Scepters, etc.)
| Adicional | Descrição |
| :--- | :--- |
| **Min. Attack Increase** | Aumenta o dano mínimo da arma. |
| **Max. Attack Increase** | Aumenta o dano máximo da arma. |
| **Critical Damage Increase** | Bônus direto no dano crítico (azul escuro). |
| **Skill Attack Increase** | Aumenta o dano base ao usar habilidades. |
| **SD Decrement Increase** | Transfere parte do dano que iria para a SD do alvo direto para o HP. |
| **SD Bypass Rate** | 10% de chance de ignorar a SD e acertar o HP (Fixo, não evolui). |

### 🧙 Cajados (Staffs)
| Adicional | Descrição |
| :--- | :--- |
| **Wizardry Increase** | Aumenta o dano mágico global. |
| **SD Bypass Rate** | 15% de chance de ignorar a SD (Fixo, não evolui). |

### 🛡️ Armaduras & Shields
| Adicional | Descrição |
| :--- | :--- |
| **Defense Increase** | Aumenta o valor de defesa da peça. |
| **Damage Decrement** | Redução percentual do dano recebido (Altamente valorizado no PvP). |
| **SD Ratio Increase** | Aumenta a taxa de dano absorvido pela SD (de 90% para 95%). |
| **Max HP/AG Increase** | Aumenta a vida total ou a stamina. |

## Refining Stones (Lower & Higher)
As Refining Stones são usadas para subir o nível do adicional amarelo (ex: Damage Decrement +3% para +7%).
- **Lower Refining Stone:** Criada a partir de itens comuns.
- **Higher Refining Stone:** Criada a partir de itens excelentes.
- **Como usar:** Arraste sobre o item que já possui um bônus de Harmony. Em caso de falha, o bônus volta para o nível inicial ou é removido (dependendo do nível).

## Itens Level 380
Itens de nível 380 (como Dragon Knight, Venom Mist, etc.) possuem dois slots para opcionais amarelos exclusivos que só podem ser ativados na Chaos Machine usando **Jewel of Guardian** e **Jewel of Harmony**. Estes bônus são fixos e não podem ser evoluídos por Refining Stones.

:::patch
Itens refinados com Harmony **não podem ser negociados via Trade**. Para vendê-los, é necessário remover o bônus no NPC Osbourne (Aida) ou usar o sistema de Loja Pessoal (P-Shop).
:::
