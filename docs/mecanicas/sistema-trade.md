# Sistema de Trade & Negociações

O Muca Brasil possui dois sistemas principais para troca de itens: o **Trade Padrão** e o
inovador **Trade Baú**.

## Trade Padrão
O sistema comum de trocas entre inventários.
- **Como usar:** Aproxime-se do jogador, pressione **D** para abrir o menu de comandos e selecione **Trade**, ou digite `/trade` e clique no jogador.
- **Capacidade:** 32 slots (8x4).
- **Limitações:** Itens com adicionais de **Jewel of Harmony** (amarelos) não podem ser trocados.

## Trade Baú (`/tradebau`)
Sistema exclusivo que permite ampliar a capacidade de negociação para **120 slots**, utilizando o espaço do baú.

### Procedimento
1. **Preparação:** Ambos os jogadores devem abrir um baú qualquer e deixar nele **apenas** os itens que serão negociados. Tudo o que estiver no baú selecionado será trocado, inclusive o **Zen**.
2. **Pedido:** Um dos jogadores (deve ser conta **Premium**) digita `/tradebau <nick>`.
3. **Aceite:** O outro jogador tem 15 segundos para aceitar digitando `/tradebau <nick-do-remetente>`.
4. **Conferência:** Uma janela exibirá os itens que estão no baú do **outro** jogador. Verifique level, opcionais e quantidade. Não é possível alterar os itens após o início.
5. **Confirmação:** Se estiver de acordo, clique no ícone do **cadeado** do baú e digite seu **Número Pessoal (NP)**.
6. **Finalização:** Quando ambos confirmarem com o NP, os itens são trocados instantaneamente.

### Observações Importantes
- **Baú de Trade:** Você pode usar o comando `/bau trade` para acessar um baú específico para negociações (acessível a todos os planos).
- **Segurança:** Se ao aceitar o trade o baú aparecer vazio, o outro jogador não colocou itens. **Não clique no cadeado**, pois isso entregará seus itens por nada.
- **Cancelamento:** Feche o baú (Esc ou V) a qualquer momento antes da confirmação final para cancelar.

## Regras e Segurança
- **Itens de 4 Adicionais:** Para negociar itens excelentes com 4 ou mais adicionais, é obrigatório ter o **Token de Segurança** ativo na conta há pelo menos 2 dias.
- **Zen:** O limite de Zen por trade segue a capacidade do baú ou inventário.
- **Itens Bloqueados:** Itens com Harmony (amarelos) são bloqueados em ambos os tipos de trade para evitar perda acidental de bônus refinados.

:::danger[Cuidado com Golpes]
A equipe Muca Brasil **jamais** solicita itens para "testes" ou pede sua senha/NP. Trades são definitivos; confira sempre os itens antes de confirmar com seu Número Pessoal.
:::
