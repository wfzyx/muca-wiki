# Sistemas de Progressão

## Reset System

O Muca Brasil opera com **reset**: ao atingir o nível exigido, o personagem volta ao **nível
1**, acumulando pontos de status a cada ciclo. Desde a atualização de dez/2024, o reset
devolve os pontos com a **distribuição base da classe** (não mais 25 fixos por atributo). Não
é preciso desequipar itens para resetar e **não há serviço de regressão** (resets não podem
ser desfeitos).

**Onde resetar:**
- **Noria [189, 127]** — Fairy Elf / Muse Elf.
- **Lorencia (bar) [121, 124]** — demais classes.

**Nível exigido por faixa de resets:**

| Faixa de resets (Free) | Nível | Faixa (Premium) | Nível |
| ---------------------- | ----- | --------------- | ----- |
| 0–10                   | 300   | 1–15            | 300   |
| 11–20                  | 325   | 16–30           | 325   |
| 21–35                  | 350   | 31–50           | 350   |
| 36–80                  | 375   | 51–140          | 375   |
| 81–250                 | 400   | 141–250         | 400   |

**Custo em Zen:**

| Faixa            | Free | Premium |
| ---------------- | ---- | ------- |
| Até 200 resets   | 30kk | 25kk    |
| 201–250 resets   | 60kk | 50kk    |

:::tip[Economia de Zen]
O limite máximo de Zen que um personagem pode carregar é **2.000.000.000 (2kkk)**. O jeito mais eficiente de farmar Zen no início é coletando do chão em eventos como **Blood Castle** e **Devil Square**, onde o drop é abundante.
:::

**Pontos de status ganhos por reset:**

| Conta   | Classe          | Pontos/reset |
| ------- | --------------- | ------------ |
| Free    | Magic Gladiator | 280          |
| Free    | Demais          | 220          |
| Premium | Magic Gladiator | 356          |
| Premium | Demais          | 280          |

:::patch
A **Liderança (Command) do Dark Lord não é cumulativa**: a cada reset é redistribuída
automaticamente pela fórmula `nº de resets × 130 pontos`.
:::

## Desafio (após 250 resets)

Opcional, para quem chegou a **250 resets e nível 400**. Adiciona **+250 resets** (total
máximo de **500**). Quem está no Desafio aparece no **Hall da Fama**.

- **NPC Golden Archers:** Lorencia [75, 151] (Blade Knight, Magic Gladiator, Soul Master,
  Dark Lord) · Noria [192, 110] (Muse Elf).
- **Custo de entrada:** 2kkk (2.000.000.000 Zen). Ao entrar, reseta para o nível 1 com 25
  pontos-base + 12 pontos adicionais.
- **Custo por reset (251–500):** Premium 200kk · Free 250kk, sempre exigindo nível 400.
- **+12 pontos por reset** durante o Desafio.

**Pontos acumulados ao iniciar o Desafio:**

| Conta   | Classe          | Pontos iniciais |
| ------- | --------------- | --------------- |
| Premium | Magic Gladiator | 89.012          |
| Premium | Demais          | 70.012          |
| Free    | Magic Gladiator | 70.012          |
| Free    | Demais          | 55.012          |

## Wings (Asas)

Equipamentos de back-slot que dão bônus de dano e absorção, craftados na Chaos Machine. As
de nível 1 liberam o voo para **Icarus**; as de nível 3 são liberadas após a 3ª classe.
Detalhes na página de [Chaos Machine](../itens-crafting/chaos-machine.md).

:::patch
Os bônus exatos de cada tier de Wings seguem a configuração do servidor — confira os Tutoriais.
:::

> ℹ️ Os comandos do cliente (incluindo `/autopick`, reset por comando e distribuição de
> pontos) estão na página **[Comandos do Cliente](./comandos.md)**.
