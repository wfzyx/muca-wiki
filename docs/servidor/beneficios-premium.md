# Planos de Conta & Benefícios Premium

O Muca Brasil oferece dois tipos de planos: **Free** (padrão) e **Premium** (via
contribuição). O plano Premium oferece diversas vantagens que aceleram o progresso e
facilitam a jogabilidade.

## Tabela Comparativa

| Recurso | Plano Free | Plano Premium |
| :--- | :--- | :--- |
| **Experiência (XP)** | 100% | 150% (Aprox.) |
| **Drop de Itens** | Padrão | Bônus em joias e Zen |
| **Resets** | Nível maior exigido | Nível reduzido (Ver [Sistemas de Progressão](../mecanicas/sistemas-progressao.md)) |
| **Pontos por Reset** | 220 (280 MG) | 280 (356 MG) |
| **Custo de Reset** | Maior (Zen) | Reduzido (Zen) |
| **Baús Extras** | 1 baú (0) | Até 20 baús (`/bau 0` a `/bau 19`) |
| **Mensagem Global (`$`)** | Não permitido | Permitido (Requer Token ativo) |
| **Comando `/autodc`** | Não disponível | Disponível |
| **Acesso à Sala 1** | Limitado (apenas resets baixos) | Prioritário |
| **Trade Baú** | Pode receber pedidos | Pode iniciar pedidos (`/tradebau`) |

## Vantagens Detalhadas

### Baús Extras
Contas Premium possuem acesso a múltiplos baús, permitindo organizar vastos estoques de itens e coleções de sets. Use os comandos `/bau 0`, `/bau 1`, etc. para alternar.
- **Dica:** O comando `/tradebau` facilita a troca de itens valiosos sem risco de roubo por limite de espaço.

### Mensagem Global (`$`)
Anuncie itens para venda ou procure grupos em todo o servidor. As mensagens aparecem no centro da tela para todos os jogadores online.
- **Custo:** 100kk Zen por mensagem.
- **Segurança:** Requer o Token ativo há pelo menos 2 dias para prevenir spam e uso indevido de contas.

### Comandos de Automação
- `/autodc <level>`: Desconecta o personagem automaticamente ao atingir o nível desejado. Ideal para quem deixa o personagem upando e quer garantir que ele não fique parado no level 400.

### Economia e Evolução
O ganho de pontos superior por reset no plano Premium resulta em personagens significativamente mais fortes a longo prazo. Além disso, o nível menor para resetar economiza horas de "up" por ciclo.

:::info[Como se tornar Premium]
O plano Premium é obtido através de créditos adquiridos por contribuições ao servidor. Acesse a área de [Contribuições](https://shop.mucabrasil.com.br/) no site oficial para mais detalhes.
:::
