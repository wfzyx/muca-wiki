# Como Contribuir com a Wiki

Esta wiki é **mantida pela comunidade** e o conteúdo é aberto. Achou algo errado ou
desatualizado? Há três formas de avisar — escolha a que for mais fácil para você.

## 1. Tenho conta no GitHub (correção direta)

Toda página tem um link **"Edit this page"** no rodapé. Ele abre o arquivo no GitHub, onde
você pode editar e enviar a sugestão (Pull Request). Também é possível
**[abrir uma issue](https://github.com/wfzyx/muca-wiki/issues/new)** descrevendo o problema.

## 2. Não tenho conta no GitHub (mais fácil)

Sem problemas — você **não precisa** de conta no GitHub:

- **Pelo fórum:** poste a correção no fórum do Muca Brasil (a maioria dos jogadores já tem
  conta no fórum). Use a seção de **[Suporte/Contato](https://www.mucabrasil.com.br/?go=contato)**
  ou o tópico de correções da wiki, se houver.
- **Formulário rápido:** _(o mantenedor pode inserir aqui um link de formulário público —
  ex.: Google Forms / Tally — para sugestões sem login)._

Ao reportar, informe: **a página**, **o que está errado** e, se possível, **a fonte correta**
(link do tutorial ou do aviso de Manutenção).

## O que vale lembrar

- **Os Tutoriais e os avisos de Manutenção do fórum são a fonte da verdade.** Posts mais
  recentes substituem os antigos.
- Nomes de itens, skills, mapas e NPCs ficam **no original do jogo** (não traduzimos).
- Valores que mudam por configuração do servidor ficam marcados com um aviso ⚙️ apontando
  para o fórum.

:::tip[Maintainer]
Para habilitar comentários direto nas páginas, dá para integrar **giscus** (usa GitHub
Discussions). Para um canal 100% sem login, criar um tópico fixo de "Correções da Wiki" no
fórum e linká-lo acima é o caminho mais simples.
:::
